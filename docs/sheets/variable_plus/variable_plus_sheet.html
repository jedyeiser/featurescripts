Variable +

Assigned · Measured · From import  |  Onshape document betterMeasure (FeatureScript 3083)  |  Feature sheet, draft 2026-11-06

Status: frame and Map output tested live 2026-11-05 (8 test features, all values matched); the Export for derive tick and the other measurement modes are not covered by that run. Needs a user version of betterMeasure before other documents see these options.

A variable feature that can also measure: distance, length, diameter, angle, radius of curvature, point coordinates. Distances and points can be read in a mate connector's frame and kept as a Map, so one variable gives a signed vector of lengths you index in any dialog (#d.delta[0]).

Left: the same two points seen in the world frame and in a mate connector rotated 90 deg about Z. Right: what Output = Map records.

Use it when / not when

Use it when
• a dimension should come from geometry, not be typed
• you need a signed offset along a custom axis (a connector)
• one measurement feeds several fields (a vector, not three variables)
• a CSV value must become a variable (mode From import)		 Use something else when
• the value is just a number: the standard Variable
• you need many named selections: Extract variables
• the measurement must stay a one-off: the Measure tool

How it works

ChoiceWhat happens
ModeAssigned (you type a value), Measured (the feature reads geometry), From import (a CSV table cell, row or column).
MeasurementDistance, Length, Diameter, Angle, Radius of curvature, Point coordinate. The result is stored as #name.
Coordinate system (new)Distance and Point coordinate: pick a mate connector; components X/Y/Z/Delta are then expressed along its axes and are signed.
Output (new)Single value, or Map: one variable holding several named lengths (keys below).

Quick start: a signed offset in a connector's frame

  1. Add Variable +, Mode Measured, Measurement Distance, type a Name (d).
  2. Pick the two entities (faces, edges, vertices or mate connectors).
  3. Tick Custom coordinate system and pick one mate connector.
  4. Set Output to Map (or keep Single value and choose Value to record under Axis measurements).
  5. Use it: #d.delta[0] is the signed offset along the connector's X, with units.

The key rule

Without a coordinate system the old behaviour is kept: single-value Along X/Y/Z are unsigned (absolute) so existing features do not change. With a frame, and for Delta and Map output in the world frame, the components are signed. Pick a connector whenever the sign matters.

Variable +, reference

Dialog parameters, outputs, limits

Dialog, in order

ModeAssigned / Measured / From import. Default Assigned.
Variable type / MeasurementAssigned: Length, Angle, Number, Any (default Any). Measured: Distance (default), Length, Diameter, Angle, Radius of curvature, Point coordinate.
NameThe variable, used as #name. A name already used by a query variable is refused. Not configurable.
ValueAssigned only. Units follow the type.
Entities to measure betweenDistance: exactly two faces, edges, vertices, bodies or mate connectors.
Minimum / MaximumDefault Minimum. Extend entities and Use axis (default off) exist only for Minimum.
Custom coordinate systemDefault off. On: pick one mate connector (Coordinate system). Components become signed.
OutputSingle value (default) or Map. In Map the Value to record / Custom direction controls are hidden.
Axis measurementsRead-only Distance, Along X, Y, Z (collapsed). Value to record (Single only): Distance, Along X/Y/Z, Along custom, Delta (vector). Custom direction in a frame is still the unsigned projection.
Length / Diameter / Angle / CurvatureAs in the original feature: Radius toggle; Angle between entities or three points with Complement; curvature at a point or minimum along the curve. No frame or Map for these.
Point coordinatePoint (vertex or mate connector), Custom coordinate system, Output, Component X / Y / Z / Vector (X, Y, Z); read-only X, Y, Z.
DescriptionUp to 256 characters.
Export for deriveDefault off. Adds the value to exportVariables for a deriving Part Studio (see the Add variables for derive sheet).

Outputs

ModeVariable
Distance, Single#name = one length.
Distance, Map#name.distance, #name.delta (vector of lengths), #name.first, #name.second (end points), in the frame or in world.
Coordinate, Single#name = X, Y or Z, or the whole vector.
Coordinate, Map#name.point (vector of lengths).

Example (tested)

Connector rotated 90 deg about Z; distance between two vertices, Map. The four keys matched the hand-computed values in the frame and in world (test features v1-v8, Part Studio 2 of betterMeasure). #d.delta[1] shows a length with units in a variable table; it was not yet tried in an extrude depth field.

Limits

• Angle, length, diameter and curvature have no frame or Map. • Export for derive with a Map value is untested. • Pure-Assigned/CSV behaviour is the original feature's. • Cannot export queries.
