Station geometry

Onshape document Publish & Drawing tools (tab folder station_tools)  |  Feature sheet, draft 2026-11-06 (FeatureScript 3083; Station table and Export tag use it, version them together)

Build the drawing-aid geometry for one part: outline wires, a line at every station, the two end points and a datum point, grouped with the part so a drawing view shows them, plus the numbers for the Station table. It replaces hand-built, easily broken drawing sketches.

Schematic plan (XY) view, y exaggerated; widths are the 4101 test part's.

Use it when / not when

Use it when
• a drawing must dimension widths / thicknesses at fixed stations
• you need a flat copy of the outline for DXF
• the same stations apply to many parts (Station definition)		 Use something else when
• you want the whole export package (DXF faces, origin, patterns): Export tag, which runs this feature
• you want the ski analysis plot / tables: Export primitive

How it works

Per view the part is projected, each station line is cut across the outline, and the rows are stored on the view composite for the Station table.

Quick start

  1. Add Station geometry after a Station definition. Pick the Part; the name prefix fills with its name.
  2. Pick a Datum (x = 0), for example the tail end point. Empty = world origin.
  3. Choose the views: Plan view (default on), Profile view, custom views.
  4. Under Station definitions pick your Station definition feature(s); optional Extra stations for this part only.
  5. In a drawing: insert the view of the <prefix> XY composite with wires shown, dimension the station lines; insert Station table with Views containing = the prefix.

The key rules

• The datum frame changes numbers, not geometry. The composite is open, so it cannot be moved; x is measured from the datum, and Flat copy at datum is the moved copy.
• Datum axes = World axes (default): only the datum's position counts. A ski's own mate connectors have Z along the ski; use Mate connector's axes only for a connector with a true X.
• The two part ends are always included (TIP / TAIL, else MIN X / MAX X), even with no stations.

Station geometry, reference

Dialog parameters (in dialog order)

PartOne solid, sheet or composite. Sheets work: face-on sheet = its own region; edge-on or curved sheet = its boundary edges dropped on the view.
Datum (measuring origin)Mate connector or vertex. Empty = world origin.
Datum axesWorld axes (default; datum is a point only, plan = world XY, profile = world XZ) or Mate connector's axes.
Name prefixStarts every body name. Filled with the part's name, follows a part change unless you typed your own. Required.
Plan viewOn by default. Datum XY.
Profile viewOff by default. Datum XZ. Shows Profile outline: Section (default; the solids cut by the datum XZ plane, exact edges, thickness on the centreline) or Silhouette (projected outline, thickest point; hundreds of tiny edges on curved parts). Section falls back to Silhouette if the plane misses the part.
View namesXY / XZ (new features) or PLAN / PROFILE (kept in saved features): names bodies, composites and table title.
Custom viewsList: View name (letters, digits, _) and View mate connector (XY plane, its X = measuring axis).
Station definitionsThe Station definition feature(s) to read, in order. Optional (none = only the two ends).
Extra stationsSame entries as Station definition, for this part only; ids must stay unique.
Geometry to createStation lines (on), Outline wires (on), Outline as surface (off: region sheet, shaded in drawings), Datum point (on), Flat copy at datum (off: copy on world XY for DXF).
Print station tableDebug group: prints each row to the notices.

Outputs

Bodies<prefix> XY (open composite: part + wires, excluded from BOM, carries the table attribute), <prefix> XY WIRES (closed: ... ST <id>, OUTLINE, DATUM, end points TIP / TAIL or MIN X / MAX X), optional REGION, optional <prefix> XY FLAT. Same for XZ / PLAN / PROFILE / custom names. Built 0.01 mm in front of the part so views show them.
PublishedVariable stationTable (rows: view, id, x, lo, hi, span in mm; end rows carry x only) and stationCount. Queries: <view>_<station id>, <view>Outline | Datum | Flat | Wires | Surface | Composite | ExtentMin | ExtentMax, with view = plan, profile or view_<name>.
Station tableSeparate custom table (Views containing, Show edge positions, Language). One table per part: Station | x | Width (plan) / Thickness (profile) | optional Lower / Upper edge. Insert it with the view filter, since a drawing brings every table.

Examples (test studio “Station tests”)

• 4101 plan + flat copy: widths 116.2 / 97.95 / 93.26 / 105.94 / 132.08 mm at x = 145 .. 1625; extents x = 0 / 1790. • 4501 plan + profile + region (open composite of core strips). • 4101E: no stations, extent rows only. • 2D_PERIPHERY / TOP_SURFACE: surface parts (half-width / height from the datum axis). • 12 features regenerated INFO with no notices at the last full check (2026-09-30).

Limits

• Open composites cannot move; export-shift handled by Export tag's hidden station frame. • A width measured exactly at a tangent-graze (4101 tail, 0.94 mm) is unstable: that is why end rows are position only. • Crowned or bevelled parts read thinner in Section than in the old silhouette. • Views show the wires only if the drawing view has wires switched on. • Not yet in a released version; a Station table from an older version fails on the newer end rows. • Untested: prefix auto-fill in the UI, a real drawing built from the published rows, station sets per part family.
