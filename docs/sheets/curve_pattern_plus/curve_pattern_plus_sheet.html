Curve pattern plus

Onshape document curve pattern +  |  Feature sheet, draft 2026-11-06 (FeatureScript 3095)

Pattern parts, faces or features along a path of edges with Linear pattern plus style spacing (spacing or total length, count or target spacing, offsets, centering), control over how copies turn, or place mate connectors only along the path.

How the spacing options place instances. The seed is the first station.

Use it when / not when

Use it when
• you want equal spacing along a curve with offsets, centering or a target spacing
• copies must follow the path, keep orientation, or stay referenced to a direction or face
• you only need mate connectors along a path		 Use something else when
• the standard Curve pattern is enough (it sweeps and has its own lock-faces mode)
• copies sit on a straight line: Linear pattern plus (Evan Reese), where this spacing model comes from

Quick start

  1. Output: Pattern, or Mate connectors only.
  2. Pattern type and the entities, faces or features to pattern (parts and mate connectors, faces, or features).
  3. Path to pattern along: edges or non-sketch wire bodies that join continuously.
  4. Spacing: pick Spacing + count, or Total length (with count or target spacing); set offsets or Centered.
  5. Orientation: leave Follow path, or choose another mode.
  6. Check the banner: “N instances, X mm apart.”

Key rules

• The seed sits at the first station. Instance i is the seed carried from the first frame to frame i, so the seed's offset from the curve is kept. With a start offset or centering, place the seed at the first station, not at the path start (otherwise copies sit off the path).
• Open paths start at the end nearest the seed (closed paths: the seed's reference geometry picks the start). Reverse path direction flips it. Mate connectors have no seed: the path starts at the first end of the edge.
• Closed path: no end offset, and the last instance is one spacing short of the start, so none doubles up.

Follow path turns each copy with the path (no roll); Keep seed orientation only moves copies.

Messages and fixes

MessageFix
“The pattern runs past the end of the path. Reduce the spacing, count or length.”Open path: spacing x (count-1), plus offsets, exceeds the length.
“The start and end offsets are longer than the path.” / “The pattern starts before the beginning of the path.”Shorten the offsets or the span.
Path edges not continuous (Onshape's standard text)Pick edges that join end to end.
“Select a direction.” / “Select a face.” / count or target spacing errorsFill the pick for Reference direction / face; count at least 1, target spacing above 0.

Curve pattern plus, reference

Dialog parameters (in dialog order), outputs, limits

Dialog

OutputPattern (default) or Mate connectors only (one seed connector placed at the first station, then patterned: one operation however many).
Pattern typePart (default; New / Add / Remove / Intersect, entities = bodies or mate connectors, merge scope), Face, or Feature (Reapply features option).
Path to pattern alongEdges, or wire bodies that are not sketch objects. Must be continuous. Reverse path direction flips the start.
Spacing typeSpacing: Spacing and Instance count (seed included). Total length: Fill the path (uses the length between the offsets) or a Total length; then Count (Instance count) or Target spacing with a Rounding type.
Rounding typeExact spacing (copies exactly Target spacing apart), Nearest value, Maximum spacing (count rounded up, so spacing never exceeds the target), Minimum spacing (rounded down, never below it); spacing = total length / gaps.
Start / End offsetLength kept clear at the start (seed distance) and at the end of an open path. Default 0.
CenteredCentre the instances between the offsets.
OrientationFollow path (no roll; default); Keep seed orientation; Reference direction (copies rolled so the normal is as close to your Direction as the path allows); Reference face (normal follows the Face at the point nearest the path; Flip normal).
Mate connector axisMate connectors only: Z along the path (default) or Z along the normal.

Outputs

• The pattern instances (or the mate connectors), standard instance queries. Banner: count and spacing in mm.
• Values for Extract variables (embedded through Variable_tools): count, spacing, span (first to last instance), pathLength, firstDistance; query lastInstance (the seed if only one); output set = instances plus seed. Not exercised by the tests (see limits).

Examples

• Bolts every 25 mm on a rail with a 10 mm start offset: Spacing 25 mm, count 8, Start offset 10 mm, seed at the first station.
• Evenly fill a curve: Total length, Fill the path, Count 12.
• Mate connectors for an assembly: Output = Mate connectors only, Total length, Target spacing 50 mm, Nearest value.

Examples are illustrative recipes built from the options above, not saved test cases.

Limits and status

• Tests (8 cases) passed 8/8 on 2026-10-10, checking positions along the path only. Not tested: rotations, Reference direction and Reference face modes, face and feature patterns, closed paths, the Extract variables output and the dialog itself.
• Not built: skip instances, match previous, manipulators, a curve as normal source. At most 2500 instances (std limit).
• Imports pin Variable_tools and curve_pattern tabs by version; a new tab version needs the user to re-pin.
