Driven offset surface

Onshape document driven_offset  |  Feature sheet, draft 2026-11-06 (FeatureScript 3070; code as of 2026-11-02)

Build sheet surfaces from one or more driven offsets of the same seed edges: rule sideways from an offset, connect the seed to its offset, or loft between several offsets. Same profile idea as Driven edge offset, but the output is a surface.

The three Surface modes, drawn as a section at one station (schematic, not an Onshape render).

Use it when / not when

Use it when
• a wall, rout or cap surface follows an offset that varies along a chain
• several offsets of one seed (inner / outer / top) must be lofted as one surface
• you want the surface split exactly where the offsets break		 Use something else when
• you need only the curve: Driven edge offset
• the offset is constant: Offset surface / Extrude
• a loft through arbitrary curves: Onshape's Loft

The three modes

SurfaceBuildsUse for
Ruled from offsetFrom each offset, a sheet reaching Distance along the frame's Width or Height (optionally both ways). One surface per offset.Walls and flanges that hang off a driven curve.
Connect source to offsetA sheet from the seed edges to the offset. One surface per offset; only the span where the offset exists, and only the longest such stretch.Surface between the seed and its offset.
Loft between profilesOne surface through two or more offsets (needs at least two). Ruled patches between neighbours, or one smooth surface with Blend through profiles.Cap walls, rout surfaces.

Quick start

  1. Pick the Surface mode, the Offset edges (seed), a Zero point (required); set Measure along and alignment as for Driven edge offset.
  2. In Offsets add one entry per offset: an Offset profile wire (X station, Y width, Z height) and optionally a Name. Loft needs two or more.
  3. Ruled mode: choose Rule along (Width or Height) and a Distance. Loft mode: decide Blend through profiles.
  4. Set Break output at: Corners and offset breaks usually suits a loft; Every source edge is the saved default.
  5. Keep offset wires if you want the driven curves too; name the surfaces.

Key rules

Offsets break togetherEvery profile must break where the others do; the feature inserts stations for the union of all breaks so section i is at the same arc length in every offset. A profile that breaks inside another's run is refused (see below).
Clean seedMicro-edges in the seed chain can make an offset step backwards and a patch be refused. Run Clean wire on the seed first (Cap_Wall failure, 2026-11).

Messages and fixes

Driven offset surface, reference

Dialog parameters in dialog order, outputs, limits

ParameterMeaning (default)
SurfaceRuled from offset (default) / Connect source to offset / Loft between profiles.
NameNames the surfaces; empty leaves them unnamed.
Offset edges, Zero point, Measure along, reference group, Offset alignmentAs Driven edge offset: Measure along defaults to Along source; Along reference shows Reference wire, Offset delta (-50..50 mm), Flip, Hold length in the reference surface; alignment defaults to Along.
Break output atWhere the offsets, sections and so faces are split: Every source edge (default; a face per source edge) or Corners and offset breaks (a face per smooth stretch). The default is kept so older features do not change; choose per feature.
Varying offset on arcsSpline (default) / Biarc fit; same meaning as in Driven edge offset (only where the offset varies on an arc; a constant offset is an exact arc either way). It is passed to the offset the surface is built from. Project notes say the loft section fits never use biarcs; the effect on the surface itself was not checked for this sheet.
OffsetsArray; each item has Offset profile (edges / wires, no construction geometry; wires only, there is no Regions source here) and Name (names that offset's wire when wires are kept).
Rule along, Distance, Both directions, Sections across the rulingRuled mode only. Rule along Width (default) or Height. Distance: how far the surface reaches (default 10 mm, up to +-10 m; negative rules the other way). Both directions (off): straddle the offset. Sections across the ruling (2-25, default 5): only matters with a reference wire, where the ruling follows the reference surface and is not straight.
Blend through profilesLoft mode only (off). Off: a ruled patch per adjacent pair, with a crease at each intermediate profile. On: one smooth surface. No effect with two offsets.
Keep offset wiresOff by default; leaves the driven curves beside the surfaces.
Corners, Ends, Spacing & approximation, DebugAs Driven edge offset (collapsed groups). Spacing: Control points x3 by default; Approximation: degree 3, tolerance 0.01 mm, max control points 15.
Surface debugPrint surface (what each offset made and what went to the loft), Only run (-1 = all), Keep section curves (the fastest way to see what the loft was given).

Outputs

• Surfaces: sheet bodies named Name. Offset wires and section curves are deleted unless Keep offset wires / Keep section curves is on.
• Published keys (Extract variables): output (the surfaces), faceCount, offsetCount, offsetWire1 ... offsetWireN (empty unless Keep offset wires is on), plus the inputs.

Examples (project notes; not re-run)

• Design_Master Cap_Wall (seed with 32 edges incl. 0.1 mm slivers, two 9-segment profiles): 10 sheets became one sheet of 16 faces on Corners and offset breaks.
• SW_Rout_Surface: 7 / 7 / 9 runs, 16 faces. (Changing Break output at once re-ran it with 3 runs, hence the saved default.)

Limits

• Patch order: exact B-spline patch, unified patch, then Onshape loft; a patch the kernel refuses becomes a hole plus a warning.
• Connect source to offset: seed trimming and corner fans are not wired up yet; ruled and single-profile modes ignore corner fills; Blend still uses opLoft.
• Loft mode: Leave open is refused.
