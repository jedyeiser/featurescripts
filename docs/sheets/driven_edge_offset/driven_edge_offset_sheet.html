Driven edge offset

Onshape document driven_offset  |  Feature sheet, draft 2026-11-06 (FeatureScript 3070; code as of 2026-11-02)

Offset a chain of edges sideways and up/down by an amount that changes along the chain, set by a profile (a wire, or regions typed in the dialog). The result is clean wires with real lines and arcs where the source has them, tangent where the source is tangent.

Use it when / not when

Use it when
• the offset varies along the chain (0 at a tip, 3 mm along the running length)
• the chain is 3D or sits on a curved reference and must follow it		 Use something else when
• the offset is constant on a planar sketch curve: Onshape's Offset curve
• you offset a face: Offset surface
• you have the offset and want the profile: Evaluate offset

How it works

1 Stations: source edges become G0 chains toward +X, sampled at stations; each gets a frame (tangent, width axis, height axis, carried by minimal rotation, not Frenet). 2 Lookup: each station reads the profile at its coordinate; Measure along says what that is (World X, distance Along source, or Along a reference wire), always from the Zero point. 3 Offset: the station moves by width and height in its frame; at a profile jump or kink the output splits and each side uses its own value. 4 Treat: G0 corners are rounded, extended or left open and trimmed where they cross; ends can land on planes. 5 Emit: straight runs become lines, circular runs arcs, the rest fitted splines with exact end tangents; one wire per connected chain.

Quick start

  1. Pick Offset edges (the source chain) and a Zero point (vertex or mate connector). This is required.
  2. Set Measure along. Along source (default) means profile X = distance from the zero point along the edges.
  3. Choose Profile source: Wire (pick a profile wire, e.g. from Create offset profile) or Regions (type it here).
  4. Check Offset alignment (Along = the chain's own frame, World = world X/Y/Z) and Break output at.
  5. Open Corners / Ends only if the chain has G0 corners or must end on a plane. Give the result a Name.
  6. If the result wobbles, tighten Spacing & approximation: tolerance about 1 um for ski radii (default 0.01 mm); raise Maximum control points to 25-30 if it warns (project notes).

Key rules

Profile reachThe profile only has data between its first and last station. Where it does not reach, no offset is made there (nothing is extrapolated).
Width and heightWidth = Y, height = Z of the profile. With Along alignment the width axis is the frame axis with the larger world-Y component; with a Reference wire, height is the reference's normal and width lies in its surface.

Driven edge offset, reference

Dialog parameters in dialog order, outputs, limits

ParameterMeaning (default)
Measure alongWhat profile X measures: World X, Along source (default), Along reference.
NameName of the result bodies. Clear it to leave them unnamed.
Offset spacing definitionShown for Along reference only: Reference wire (one pick), Offset delta (-50 to 50 mm, default 0; measures along a curve this far from the wire), Flip offset delta, Hold length in the reference surface (off). Delta only changes where each station reads the profile; it never moves a point.
Offset alignmentAlong (default) or World.
Break output atEvery source edge (default; one output edge per source edge) or Corners and offset breaks (tangent-continuous edges run together).
Varying offset on arcsSpline (default) or Biarc fit. Applies only where the source is an arc and the offset changes along it, so the result is not an arc. Spline: one spline per run, tangent to its neighbours. Biarc fit: two or more tangent circular arcs per run, matching both end directions within the approximation tolerance; a spline instead where that would take more than 8 arcs. A constant offset of an arc is an exact arc either way. Biarc adds edges; Spline keeps one per run.
Offset edgesThe source edges or wires (construction geometry excluded).
Profile sourceWire (default) or Regions. Wire: Offset profile = the profile edges. Regions: the same Regions / Intersections table as Create offset profile; no wire is made.
CornersCollapsed group. Where the offset gaps: Round with an arc (default, a true arc centred on the vertex) / Extend to a sharp corner / Leave open. Where the offset crosses: Trim to the crossing (default) / Leave crossing.
EndsCollapsed. Start plane, End plane (mate connector or planar face; start = low-X end), optional Start / End direction (the slope at the plane), Allow extension (on): off leaves an offset that stops short alone.
Zero pointVertex or mate connector; all profile coordinates are measured from it. Required.
Spacing & approximationOffset spacing: Control points (multiplier 2-10, default 3) / Points per edge (10-50, 25) / Distance along (0.1-50 mm, 10). Join runs into one wire per link (on). Join tangent segments into one edge (off). Approximation: Target degree (2.., default 3), Tolerance (default 0.01 mm), Maximum control points (4.., default 15). Station count must stay stable between edits or the frame seed can move.
DebugPrint chains / offset / frame tables, Show offset frames, offsets, reference offset, chain ends (green start, red end), Visualize continuity. No effect on geometry.

Outputs

• Bodies: one wire per connected chain (or loose curves if Join runs is off), named by Name.
• Published keys (for Extract variables): output, startVertex, endVertex (start of each wire at its source start / the other end), startEdge, endEdge, cornerArcs (the true arcs that round G0 corners), plus the inputs.

Examples and evidence (project notes; not re-run)

• Corner test: outside gaps measured 2w·sin(θ/2) to 3 decimals; a 123.5 deg inside corner overlapped 9.311 mm.
• Regions source vs a profile wire (tests D1-D5): identical within 1e-3 mm.

Limits

• Length always follows the source edges; fully reference-driven length/width is an open design question.
• A profile break always splits the output; no per-break None / Line join exists yet.
• Fit curvature resolution is about 8·tol/L²: a loose tolerance wobbles on very long radii.
• Not verified for this sheet: behaviour of Biarc fit on live geometry and whether the pinned library versions in your document already include the Varying offset on arcs option.
