Export tag

Publish & Drawing tools  |  Onshape document Publish & Drawing tools (tab export_tag)  |  Feature sheet, draft 2026-11-06  |  not yet versioned (needs a document version, together with Station geometry)

Tell the export app what to export for one body or one composite (solid formats, DXF plan / profile, station views, export origin), and let the feature build the geometry that export needs: DXF faces, an optional shifted copy and the station views.

Schematic. A tagged part anywhere in the model becomes DXF surface bodies placed from the export origin (here 1st quadrant, 10 mm buffers), patterned 3 x 1 with a clearance.

Use it when / not when

Use it when
• a part (or composite) must be exported as DXF, with a known name and origin
• several copies of one outline should sit in one DXF (a pattern)
• the part's drawing needs station views and a Station table
• an app or the API tool should read one record of the export intent		 Use something else when
• you want the file written now: the tag only records solid formats; the app / API tool exports
• you need true nesting of parts on a sheet (not built)
• you want the ski's primitive drawing: Export primitive

How it works

• Input: one body or composite, plus a name, an optional export origin and the DXF / solid / station options.
• FeatureScript builds: DXF faces (surface bodies on XY / XZ, in a composite), an optional shifted copy <name> EXPORT, the station views (Station geometry).
• FeatureScript only records: STEP / IGES / STL / Parasolid, file names, release prefix. The app / API tool does the exporting from the attribute publishExportTag and the variable exportTag.

Quick start

  1. Part: pick one body or one composite. The part's name is stored; press Get Part Name if you rename it later.
  2. Check Export name (empty = the stored part name). It names every generated body and view.
  3. Export info: tick Export solid (and the formats) and / or Export DXF; set Plan (XY) and / or Profile (XZ) to Projection of the part or Selected faces.
  4. Optional: Export origin (mate connector, or a quadrant with buffers); Pattern the DXF faces for several copies.
  5. Optional: tick Station table, pick the Station definition(s) and a datum.
  6. Read the feature's info message: it lists the surface bodies built per view, the pattern and any warnings.

Key rules

• One part per tag. A body inside a composite is exported as itself; tag the composite separately to export the composite.
• The export origin always shifts the DXF faces (composites too). A shifted copy, and station views built on a copy, exist for single bodies only.
• Keep export names distinct across tags: the Station table finds views by a substring match on the export name.

Outputs

BodiesDXF faces <name> XY EXPORT (copies ..._PATTERN_n, n along X then Y), composite <name> XY DXF (always, even for one face; XZ likewise); shifted copy <name> EXPORT; station views <name> XY / XZ (built by Station geometry).
AttributepublishExportTag (schema exportTag/1) on the tagged body: name, part ids, solid formats, dxf, drawing (incl. layout per view: body names with x / lo / hi / span for ordinate dimensions), origin, shiftedCopy.
Variable, queriesVariable exportTag (the same map; read it with Extract variables); queries exportPlan, exportProfile.

Examples

• Flat DXF, one part: Export DXF, Plan = Projection, Origin = 1st quadrant. Result: <name> XY EXPORT in <name> XY DXF.
• Three copies for one cut: add Pattern, 3 x 1, Pitch. Tested with a 1 x 3 pattern of a projected plan (pitch 142.26 mm, arcs kept).
• Part with station table: tick Station table, pick the Station definition, Plan view on; in the drawing insert the table with Views containing = the export name.

Limits and not verified

• Solid formats, file names and the release prefix are only recorded; exporting is the app's / API tool's job. There is no drawing-export flag in the tag.
• Name-clash warnings only see tags earlier in the tree.
• Verified on real parts (2026-10-29): plan projection, quadrant, pattern, section profile, selected flat face, station views in place and on a shifted copy. Not verified: selected tilted or curved faces, an attribute surviving a composite rebuild, a real drawing built from drawing.layout, and the dialog's rendering of every conditional.
• The regression build (build_export_tag_tests.py, ZT1-ZT8) has not been run.
