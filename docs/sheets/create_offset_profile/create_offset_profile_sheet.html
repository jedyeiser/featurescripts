Create offset profile

Onshape document driven_offset  |  Feature sheet, draft 2026-11-06 (FeatureScript 3083; matches the 2026-09-29 deck)

Type an offset profile as regions or points (width and height against station) and get exact profile wires for Driven edge offset and Driven offset surface, instead of sketching one by hand.

Schematic (computed from the documented shape rules, not an Onshape render): a table of regions becomes one wire; the consumer offsets with it.

Use it when / not when

Use it when
• the offset is defined by regions: tip, running length, tail
• width or height ramps, holds or steps along X
• stations should come from the part (a vertex or mate connector)		 Use something else when
• Driven edge offset only: its own Profile source = Regions needs no wire
• the offset already exists as geometry: Evaluate offset
• the profile is freehand: sketch it

How it works

IdeaMeaning
Profile coordinatesX = station (world X), Y = width offset, Z = height offset. The wires are data; the consumer measures from its own zero point.
Piece = one wireA continuous stretch of the profile. Touching regions with equal values join into one piece.
BreakWhere the offset jumps (touching regions with different values, or two points at one station) or is undefined (a gap in X), the profile ends and a new piece starts. No connector edge is made; whether and how a break is joined is the consumer's choice.
ExactExact Bezier segments (line, smootherstep ramp, Hermite blend); nothing is sampled. A buffer into a Smooth ramp is C2; a Linear corner only G0.

Quick start

  1. Mode Regions: add a region per stretch (name it by role: Tip, RSL, Tail).
  2. Set Start and End station (Enter X, or At point = a vertex / mate connector plus a signed distance along X).
  3. Choose a Shape and enter widths and heights.
  4. Between two regions, open the matching Intersection: leave Blend off, or turn it on for a smooth bridge.
  5. Check the piece count: Print segments (Debug) lists every piece and sub-segment.
  6. Pick the wires as Offset profile in Driven edge offset or Driven offset surface.

Key rules

Names uniqueIntersections are kept by region name; two regions with one name is an error. Regions may touch but not overlap.
Stations are world XPicked points give their world X; place stations accordingly on a part measured along its reference.

Messages and fixes

MessageFix

Region 'x': the buffers are as long as the region or longer. / the start and end stations coincide.Shorten the buffers; give the region a length.
The blends into region 'x' reach past each other... / The blend between 'A' and 'B' has no length but the offset jumps...Shorten the distances (or drag the arrows); give a jump a blend distance, or leave a gap in X.

Create offset profile, reference

Dialog parameters in dialog order, outputs, limits

Regions

Intersection

Points
ParameterMeaning (default)
ModeRegions (default) or Points.
Regions: NameEmpty = Region n. Up to 64 characters. Must differ.
Start / End stationEnter X (default; type Start X / End X, world X) or At point: Start point (vertex or mate connector, one can be created in the field) plus Start offset along X (signed). A region may be entered toward -X (start > end).
ShapeConstant, Linear (default), Smooth (smootherstep: flat, zero curvature at both ends, no overshoot) or Quadratic (a parabola). Quadratic adds Flat at Start (default) or End: the end with zero slope; the other meets its neighbour at a kink.
Width, heightConstant: one Width and Height. Otherwise Start / End width and Start / End height. Width and height share the region's shape.
Start / End bufferHold the end value for this distance in from that end; the change runs between the buffers. Not for Constant. Buffers must total less than the region.
IntersectionsOne per pair of consecutive regions, rebuilt automatically and labelled by names (First / Second region are read-only). Blend (off): off joins touching regions with equal values, else breaks. On: Continuity with first region (G1 default), Distance into first region, Continuity with second region (G1), Distance into second region; a Hermite bridge, G0 / G1 / G2. Two drag arrows per blend on the model while editing; both distances 0 only works across a gap in X.
PointsList of points: Station (Enter X / At point, with Offset along X), Width, Height, and To next point: Smooth (default; flat at both, no overshoot), Linear, or Hold (keep the value to the next point, then break; ignored on the last point). Two points at one station with different values are a jump.
DebugPrint segments: every piece and sub-segment with stations, degree and end values.

Region shapes from live test wires: Constant, Linear, Smooth, Quadratic.

Outputs

• Bodies: one wire per piece, each joined from exact Bezier edges (no Name parameter). Blend edges are shown magenta while editing.
• Published keys (Extract variables): output (all pieces), piece1 ... pieceN (station order), startVertex, endVertex, breakVertices (piece ends on both sides of every break), pieceCount, breakCount, breakStations, startStation, endStation.

Examples (studio "Offset profile tests"; notes, not re-run)

• T1: Tip w 0, RSL w 3, Tail w 0 gives three pieces, breaks at 0 and 1000, four break vertices. • T5: two points at one station with different values: two pieces. • T10: a region entered toward -X (start 10100, end 10000) works.
• Driven edge offset's Profile source: Regions uses the same table; tests D1-D5 matched the wire within 1e-3 mm.

Limits

• Breaks only split the output today: Driven edge offset / Driven offset surface have no per-break None / Line join yet.
• One shape per region for width and height together.
