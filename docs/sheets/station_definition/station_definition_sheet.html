Station definition

Onshape document Publish & Drawing tools (tab folder station_tools)  |  Feature sheet, draft 2026-11-06 (FeatureScript 3083; versioned together with Station geometry)

Name the places along a part where drawings measure it, once: single points and evenly spaced stations along a line or between two points. Station geometry and Export tag then pick this feature.

Schematic, not to scale (4101 test positions, datum at the tail): single points TAIL, MRS, TIP and one N-between entry.

Use it when / not when

Use it when
• several parts or views share the same measuring stations
• you want station ids that stay stable when a station is added or removed
• drawings need width / thickness tables at fixed places		 Use something else when
• one part needs a one-off station: use Extra stations inside Station geometry
• you need the measurements themselves: add Station geometry (this feature makes no geometry)

How it works

Selections (vertices, mate connectors, line edges) are resolved to plain points and directions here, so nothing downstream breaks when the picked geometry changes later.

Quick start

  1. Add Station definition above the features that use it (it must regenerate before them).
  2. Add a station (Stations list). Choose its type, give it a name, pick the point(s) or the line.
  3. For N stations entries, set Number of stations (ends included) and, if wanted, First number (for example 0).
  4. Choose Station table language (English / Deutsch) for the drawing table.
  5. Check the message (“N stations.”); Print stations lists positions in the notices.
  6. In Station geometry (or Export tag) pick this feature under Station definitions.

The key rules

• Names are ids. Letters, digits and underscore only (anything else becomes _); they must be unique across the whole definition. Drawing dimensions follow the id, not the row.
• Numbering of line / between entries runs toward +X (else +Y, else +Z) unless Reverse numbering is on. An empty name numbers its stations 1 .. N.
• Station positions are absolute. A part later moved with an export shift is handled by Station geometry's hidden station frame, not here.

Troubleshooting

MessageCause and fix
Station N has no name.A Single point entry needs a name (empty names are fine only for line / between entries).
Station X: select a point. / select a line.The entry's pick is empty. Pick a vertex, point or mate connector; or a straight (line) edge.
Station X: the two ends coincide.Both ends of the line or between-pair are the same point.
Two stations are named X. Station names must be unique.Rename; remember that name_1 ... name_N from a line entry count too.

Station definition, reference

Dialog parameters (in dialog order)

Also store as # variable (optional)Variable name for your own expressions. Empty (default for new features) = none; saved features keep the older default stations. Publish features read the feature itself, not the variable.
Station table languageEnglish (default) or Deutsch: headings of the Station table made from these stations (the table can override it).
StationsList of entries; each has the fields below. The item label shows the station name.
  Station typeSingle point (default) / N stations along a line / N stations between two points.
  Station name (or name stem)Up to 64 characters. Single point: the id (required). N stations: ids <name>_<n>, or just n if empty.
  Point / first pointOne vertex, point or mate connector (its origin). Shown for Single point and Between.
  Second pointBetween only: the other end.
  LineLine entries only: one straight edge; its two ends are the first and last station.
  Number of stationsInteger 2 to 200, default 5. Evenly spaced, both ends included; each measures perpendicular to the line.
  First number0 to 1000, default 1: the number of the first station (0 gives name_0 ... name_(N-1)).
  Reverse numberingOff: numbers rise toward +X (else +Y, else +Z). On: the other way.
Print stationsPrints each station's id, position (mm) and direction to the notices.

Outputs

GeometryNone. The feature info reads “N stations” (plus “also in #name” if a variable was set).
Published keysstationSet (schema stationSet/1: stations with id, group, origin, direction, hasDirection; plus language en / de) and stationCount, in the feature's producer slot (extract_outputs). Read by Station geometry / Export tag; shown in Extract variables.
# variableOnly if named: the same station set map.

Examples

• Fixture (4101, test studio “Station tests”): a point set TAIL / EDA / SPA, plus N stations between EDA and SPA, N = 5: x = 145 / 515 / 885 / 1255 / 1625 mm; Station geometry measured widths 116.2 / 97.95 / 93.26 / 105.94 / 132.08 mm.
• Numbered from zero, German: fixture “Numbered 0-4 DE” gives stations 0 to 4 with language Deutsch (checked by eval).

Limits

• Positions are fixed at definition time (plain points); they do not follow the part if it is later edited without moving the picked points.
• Place it above every feature that picks it. Several definitions may be picked; ids must be unique across them and across a part's Extra stations.
• Mixed versions: Station definition, Station geometry and Station table should be versioned together. Not yet in a released version of the document (as of 2026-11-06).
• The editing dialog (type switching, label text) was not re-checked in the UI for this sheet.
