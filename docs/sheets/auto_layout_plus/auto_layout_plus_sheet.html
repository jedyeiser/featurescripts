Auto layout plus

Onshape document Publish & Drawing tools  |  Feature sheet, draft 2026-11-06 (FeatureScript 3095; not yet in a released document version)

Lay out selected solids, surfaces and composite parts flat on the XY plane of a mate connector, packed by bounding box with set gaps, optionally in fixed-size sheets, optionally with small parts nested into the holes of big ones.

Use it when / not when

Use it when
• you need a flat nest of parts (cut file, DXF, drawing sheet) from parts that sit anywhere
• the set mixes solids, surfaces and composites
• you want a repeatable layout that follows when the parts change		 Use something else when
• you need rotation to any angle or true-outline (non-box) nesting: the packing is by bounding box, only 90 degrees
• you want the original Onshape “Auto Layout” example for simple solids
• you just want evenly spaced copies: Linear pattern

How it works

StepWhat the feature does
MeasureEach body's bounding box in the origin frame (length = X, width = Y). A selected composite moves with its members.
PackLongest side first; free-rectangle (MaxRects) packing: the lowest-x, then lowest-y free corner that fits. Fills Y first, then continues along X. Optional 90 degree turn tries both orientations.
PlaceMoves (or copies) every body to its slot, lowest point on the origin plane, original orientation kept.

Quick start

  1. Select Bodies to lay out (solids, surfaces, composites).
  2. Pick the Pattern origin: a mate connector (existing or made in the field) or a vertex. X and Y of that frame are the layout's length and width.
  3. Set X buffer / Y buffer (gap between bodies and margin from the origin).
  4. Optional: tick Limit layout width (and Limit layout length) to pack into sheets of a fixed size.
  5. Leave Show layout preview on while editing: cyan boxes per body, magenta sheet outlines.
  6. Choose Copy bodies to keep the originals, and Create composite part to group the result; accept.

The key rules

• Length is X, width is Y. Layout width limits Y; Layout length limits X; the next sheet is offset along +Y (pitch 1.1 x the layout width).
• A vertex gives world axes, a mate connector gives its own axes. Orient the connector to choose the layout direction.
• The packing is by bounding box, not outline. Curved or L-shaped parts leave unused corners unless nesting is on.

Auto layout plus, reference

Dialog parameters (in dialog order)

Bodies to lay outSolids, surfaces, composites (modifiable only).
Pattern originOne mate connector or vertex. Vertex = world axes. Required.
X buffer, Y bufferLength, 0 to 1000 mm, default 10 mm each. Gap between bodies and margin from the origin. Remembered between uses.
Limit layout widthOff = one unbounded row of columns. On shows Layout width (Y) (1 mm to 100 m, default 2000 mm) and Limit layout length.
Limit layout lengthOn shows Layout length (X) (same bounds). A full sheet starts a new one at +Y. Only available with a width limit.
Allow 90 degree rotationEach body may be turned 90 degrees about the origin Z, whichever packs better. Off by default.
Nest bodies inside holesOpt-in. Places smaller flat bodies into holes and windows of larger ones (outline and holes from the largest flat face, 5 mm resolution, nested bodies keep orientation). Slower; not for non-flat parts.
Spread bodies in holesShown with nesting. On: nested bodies slide to the middle of their free range. Off: packed against the first wall.
Place on origin planeOn: each body's lowest point goes to the origin plane. Off: Z unchanged.
Copy bodiesCopy instead of move; originals stay.
Create composite part, nameGroups the laid-out bodies in an open composite named by Composite name (default Layout).
Show layout previewDebug geometry while editing: cyan box per body, magenta sheet outlines, origin frame.

Defaults above are those coded in the feature's saved-feature defaults map; confirm the first-use dialog values in Onshape.

Outputs

Moved or copied bodies, and the optional composite part. It publishes no query variables or keys. The feature message reports sheets used and bodies nested.

Nesting: small plates sit in the windows of a large part.

 Examples (regression studio, publish_tools document; 8 cases, all passing as of 2026-10-29)
T1 column wrap · T2 no width limit · T3 length limit gives sheet 2 · T4 composite name · T5 composite inputs warn · T6, T7 nesting spread off / on · T8 nesting off. On a real ski-part test, 5 of 6 small plates nested into the windows.

Limits

• Bounding-box packing: curved parts waste space unless nesting is on.
• A composite cannot contain another composite: selected composites are laid out but stay separate from the new composite.
• Nesting is opt-in, flat parts only; its cost is mostly the outline sampling (about 3 s per regen on the user's test with spread on, after tuning).
• Not covered by the automated tests: rotation (tested by hand in the UI), implicit connector pick (UI only), nesting with copy mode, rotation or non-flat bodies, composite rename.
• Not in a released version of the document yet.
