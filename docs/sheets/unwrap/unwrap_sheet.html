Unwrap

Unwrap (edges, constant-thickness plates, solids, faces)  |  Onshape document Design_Master (driven_offset; unwrap.fs, unwrap_part.fs, undrape_utils.fs)  |  Feature sheet, draft 2026-11-06 (FeatureScript 3070)

Flatten geometry that is wrapped along a planar reference curve (a ski's camber and rocker profile, say) onto a plane, keeping the lengths along the curve you choose. It gives you the flat blank of a bent laminate, core or edge.

Schematic (not live data): wrapped along W, then flat; length is kept along W offset by d.

Use it when / not when

Use it when
• a part or curve lies along a planar tangent chain and you need its flat shape (laminates, base, topsheet, core, extensions, edges)
• you need the flat length, volume change and line/arc/spline content checked for you
• the part is a plate with a draped surface (topsheet): undrape measures and reports the deformation		 Use something else when
• the reference curves in 3D, runs across world X, or turns back in X (refused)
• you want to bend or map curves to another curve, not flatten: Wrap Curve / Deform (curveMapping)
• the shape is a sphere, saddle or other non-developable surface that must keep every length (impossible; only plates are undraped)

How it works: four modes, one chart

Every point near W gets chart coordinates: arc length s along W, offset v across W's plane, height h off the swept surface. The flat result is x = s - d*theta(s), y = -v, z = h, placed in the origin's frame with the alignment point at the origin. Only the curve at offset d keeps its length; other heights stretch by (1 - kappa*d) / (1 - kappa*h), which is why a part sitting high on a curved stretch changes volume.

Inputs and outputs: Edges/wires gives one wire body per source body. Constant-thickness part: plates (flat or draped), one flat plate per source. Part (solid): any solid along W, one flat solid per source. Faces/surfaces: faces or sheets, one flat sheet per source body.

Quick start

  1. Pick Unwrap (mode) and the geometry (Edges to unwrap, Parts to unwrap or Faces to unwrap).
  2. Pick the Wrapped reference (plates: or Section by a face, see page 2).
  3. Choose the length to keep. Edges, Part, Faces: Preserve length = Along an offset and set Offset to the part's height above W. Plates: set Target offset to the plate's mid height above W.
  4. Pick the Wrapped alignment point (a mate connector or vertex within W's X span) and the Unwrapped origin (a mate connector, plane or planar face).
  5. Optional: press Read names and properties to fill the Outputs table (names, materials).
  6. Read the notice: Length along the preserved curve: ... mm wrapped -> ... mm flat; volume x.... The two lengths should agree.

Key rules

• W must be one planar tangent chain (joints within 1 degree), with X rising steadily along it.
• The alignment point's X must lie inside W's X span (the message names the span).
• Volume x is not expected to be 1 for a solid off the preserved curve on a bend: set the offset to the part's height (explainer 2.3).

Outputs and examples

• Bodies: one flat wire / plate / solid / sheet per source body, placed in the origin's frame; named from the Outputs table.
• Published values (through Variable_tools' embedStandardOutputs): lengthWrapped, lengthFlat, volumeRatio per body, plus line, arc and spline counts. Exact key spelling not re-checked on this sheet.
• Test studio examples (explainer 2.4; wrapped -> flat, mm): base plate 1789.587 -> 1789.589; core 1500.000 -> 1500.000; topsheet by own section 1827.693 -> 1827.693. Examples live in the Design_Master test copies; numbers are the explainer's, not re-run here.

Status (what is not settled)

• U-turn default (literal vs blend at the topsheet tip and tail): the choice is still open; the code default is literal.
• Also open: the about 9 degree transition shear on topsheet flaps, runtime, and 5-10 um fit error within 0.2 mm of transition vertices.
• A single constant d is used per part; a variable neutral-axis length curve for solids is not built, so layers unwrapped on their own curves do not coincide in the flat.
• Faces mode: a 64-face core test gives 2 sheets instead of 1 (faces differing over about 1 um do not sew). Not built: surface projection / thicken, composite parts, mate connectors as input.

Limits

• W: planar, one tangent chain, X rising; geometry past W's centre of curvature is refused.
• Part mode over a curved reference refuses what it cannot build instead of building it wrong. Not handled: bosses, tunnels along Y, filleted or stepped hole floors, ring walls that are not ruled; closed chains turning more than 180 degrees.
• Plates: the accuracy budget is 0.01 mm; the flat outline can differ from the plan where the plate is draped (undrape is a deformation, reported as stretch and shear).
• Always pull the tab before editing: the document pins unwrap, undrape_utils and unwrap_part to one edge_offset_utils version.
