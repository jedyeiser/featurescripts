Measure curve distance

Measure curve distance  |  Onshape document curveMapping_public (measureBetweenCurves.fs, FeatureScript 3083)  |  Feature sheet, draft 2026-11-06 (no version pinned on this sheet)

Sample points along one curve and measure how far each is from a second set of curves. The results go into a table, one row per point: a quick inspection of gaps, clearances and offsets between edges or wire bodies.

Schematic (not live data) of the three measurement types on the same two curves. Dots on the lower curve are the sample points; lines show where each distance is read.

Use it when / not when

Use it when
• you want a table of distances from one smooth curve to other edges or wires (e.g. how far an offset curve sits from a profile along its length)
• you need the distance along a chosen axis, or normal to the curve		 Use something else when
• you need one number between two bodies: Onshape's Measure
• you need a surface-to-surface comparison (this works on edges and wires only)
• the From curve is not one G1 chain (it is refused)

How it works

Measure from must be a single G1-continuous chain; points are placed along it by count or spacing. Measure to may be any edges or wires (G0). Closest reads the nearest distance from each point to the To set. Normal dist and Along axis cut a plane through each point that contains the measurement direction and slices across the To curves; the distance is the offset to where it cuts, measured along that direction, so it is signed. A point with no crossing gets no row.

Quick start

  1. Pick the Measurement Type (Normal dist is the default) and give the table a Measurement Name.
  2. Select Measure from (one G1 chain of edges, or a wire body) and Measure to.
  3. Choose points: Number of points (2 to 200, default 20) or Point spacing with a reference and a distance.
  4. For Along axis, pick the measurement direction (World X / Y / Z, or custom).
  5. Read the table (see Outputs on page 2).

Key rules

• From = G1 chain, To = any G0 set.
• Normal dist and Along axis need a planar From curve (the code fits a plane through the sample points).
• The table is shared by all Measure features in the Part Studio; rows of a deleted feature stay until you clear them.

Outputs

• No geometry is created. Debug points and lines are display only.
• Table “Measure between curves”: one titled table per Measure feature (“Measurement between curves: <name>”) with columns Point #, From point, To point, Distance. Points print as (x, y, z) in the chosen units. With nothing measured it shows “(No Data)”.
• Storage: rows are saved as one attribute on the Part Studio origin, keyed by feature, so every Measure feature adds to the same table set.
• Distance sign: Closest is the plain distance; Normal dist and Along axis are the component along the chosen direction (signed). No published variables.

Examples

• Closest, 20 points: a gap profile between an offset curve and its source.
• Normal dist, spacing 10 mm from a mate connector: clearances at regular stations along a profile.
• Along axis (World Z), spacing along X: heights of one curve above another at equal X stations.
These describe use; no worked example is recorded in the repository.

Status and limits

• Not live-verified: the directional modes (Normal dist, Along axis) and the table's persistence were never confirmed in Onshape in the project notes; the public features have no tests. Treat results as unchecked until compared with a known distance.
• Rows of deleted features persist until Clear accumulated data is cycled (the feature cannot remove its own entry).
• Up to 1000 points per measurement (spacing guard); Number of points caps at 200.
• Samples with no crossing of the To curves are silently skipped, so the row count can be lower than the point count.
• Where the table appears in Onshape's UI was not checked here.
