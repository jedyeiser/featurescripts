Evaluate offset

Onshape document driven_offset  |  Feature sheet, draft 2026-11-06 (FeatureScript 3070; code as of 2026-10-01)

Driven edge offset run backwards: give it the edges an offset is measured from and the edges it is measured to, and it builds the offset profile wire (X station, Y width, Z height) that Driven edge offset would need to turn one into the other.

Dialog

Schematic (computed, not an Onshape render): the target is measured at every reference station; the result is a profile wire.

Use it when / not when

Use it when
• a target curve already exists (a measured edge, an imported wall) and you want its offset as a profile
• you then want to drive other edges with the same offset		 Use something else when
• you know the offset values: Create offset profile
• you only need a single distance: a measure tool
• you want to make the offset: Driven edge offset

How it works

1 It samples the reference edges at exactly the stations Driven edge offset would use (same chain, spacing and transported frames). 2 At each station a section plane (normal to the frame's length axis: chain tangent for Along, world X for World) cuts the target. 3 The cut point is read in the station's frame: width along the width axis, height along the height axis. 4 Every target vertex gets an exact station pair, so a target corner is a corner in the profile. 5 The profile breaks (one wire per continuous piece) where the target does not reach the section plane or where the offset steps. It starts and stops where the target does.

Quick start

  1. Pick Reference edges (what Driven edge offset would offset) and Target edges (what you measure to).
  2. Pick the Zero point (required, same one Driven edge offset will use).
  3. Set Measure along (Along source or World X) and Offset alignment to what the consumer will use.
  4. Open Spacing & approximation and set the same spacing Driven edge offset will use (3D frames depend on it). Use about 5 mm spacing for accuracy.
  5. Check the result (optionally Show measurements), then feed the wires into Driven edge offset or Driven offset surface as the offset profile.

Key rules

Match the consumerMeasure along, alignment, zero point and spacing are Driven edge offset's own settings under the same parameter keys; a profile only reproduces the target if the consumer uses the same ones.
Along referenceMeasure along = Along reference is refused (v1): use Along source or World X.

DebugShow measurements (draws each station to the target point it found), Print profile table (coordinate, width, height, breaks).

Outputs

• Bodies: one wire per continuous piece. A run that is straight within tolerance is a line, otherwise a fitted spline; there are no arcs, and no exact end derivatives.
• Published keys (Extract variables): output (all pieces), piece1 ... pieceN, startVertex, endVertex, breakVertices, breakStations (middle of each jump or gap), startStation, endStation, plus the inputs (reference and target).

Examples and evidence (project notes; not re-run)

• Test studio "Evaluate offset tests", 11/11 passed (research note). Measured against the original target: E1 line, E2 arc R400, E3 jump (2 pieces), E4 World frame / World X, E5 outside G0 corner, E6 inside G0 corner: worst 5.5 um.
• Round trip R2-R6 (measured profile fed back to Driven edge offset): worst 10.4 um against the original target. All at 5 mm spacing; at 71 mm spacing only approximate.
• At a G0 corner in the reference, inside the turn the cuts from the wrong side are rejected and the run fit bridges the gap; the forward offset trims it again.

Limits

• No Measure along = Reference wire (the inverse of that placement is a different cut); 3D reference not tested; no icon yet.
• Accuracy depends on spacing: use about 5 mm, and the same spacing in Driven edge offset.
• The profile is fitted: it reproduces the target within the approximation tolerance, not exactly.
