Build a ski's primitive drawing from its solid: baseline, profile, unwrapped footprint and a radius (or curvature) plot, stacked as bands in one closed composite, plus six data tables (including the cavity depth column) for the drawing and the factory.

Use it when / not when

Use it when
• a ski or board volume needs its primitive drawing and data tables
• you need rocker / camber, sidecut radius, thickness and (optionally) cavity depth along the ski
• the factory wants the numbers in English or German		 Use something else when
• you only need a flat DXF or station views: Export tag, Station geometry
• you want the EI curve itself: Cross section / EI tools

How it works

• Inputs: the ski Volume, the contact points FCP (forebody, on the tip side) and ACP, and a name prefix. MRS (mid running surface) is halfway between them.
• The volume is cut by the datum XZ plane: BOTTOM / TOP / end wires give the profile; its bottom edge is the baseline. The base outline is unwrapped along the bottom wire to the footprint, from which the sidecut radius is measured.
• Everything is drawn as points and wires in one closed composite <prefix> PRIMITIVE (movable as a unit). The tables are stored in its attribute; the Primitive tables custom table shows them in the drawing.

Quick start

  1. Volume: pick the ski solid. The Name prefix fills in from it.
  2. FCP and ACP: pick vertices, points or mate connectors (they must be apart along the datum X); optionally a Datum.
  3. Optional: Cavity depth group: pick the cavity depth profile (a wire).
  4. Optional: Stiffness group: pick a Target EI wire for the EI band and deflection.
  5. Read the info message (RSL, average radius, rows) and insert the Primitive tables in the drawing.

Key rules

• FCP is on the tip side; never assume ACP > FCP in x. x is measured from the datum, s along the bottom wire.
• Scaled bands (Auto scale, default): baseline and profile heights (z) are stretched to fill a fixed band height; x stays 1:1. Anything reading z from the band geometry sees it scaled; tables and the attribute are exact.
• Cavity depth is measured along the bottom wire's normal (the same direction as thck), not vertically.

Messages and fixes

MessageFix
“Select the volume (the ski part).” / “Enter a name prefix...”Pick the volume; type a prefix (e.g. the model name).
Info “the mid plane cuts the volume in N loops; the longest is used”A slot or swallowtail splits the section; rows outside the longest piece have no thickness or cavity depth. Set Profile source to picked wires (one closed loop).
“The profile wires / baseline wires overlap or do not form a clean wire”Pick only the profile or baseline body, not extra sketch lines that touch it.
“The cavity depth profile has no length once projected...”Pick a wire that lies in or projects onto the datum XZ plane.

Dialog, in order

Inputs
Volume, Name prefixThe ski / board solid (one part); a prefix starting every body name (required, filled from the volume).
FCP / ACPForebody / aftbody contact points: vertex, point or mate connector. MP (optional, several allowed for a snowboard).
Datum, Datum axesMeasuring origin; empty = world origin. Axes: World axes (datum is a point only) (default) or Mate connector's axes (its X along the ski, Z up).
Profile, baseline and footprint source (collapsed)
Profile / Baseline / Footprint sourceFrom the volume (default) or From picked wires. Use picked profile wires when the mid-plane section splits (swallowtail); pick only the baseline body, not generated measurement sketch lines.
Key locations, SW rout (collapsed)
Extra key points, SW rout surfaceNamed points (a Table 3 row, plot tick; names must differ from FCP, ACP, MRS, XS1, XS2, TIP, TAIL). Optional SW rout surface, start and stop add Table 4.
Cavity depth (collapsed)
Cavity depth profileOptional wire for the bottom of the lid cavity (edges or a wire body, connected). One not in the datum XZ plane is projected onto it. Drawn in the profile band (<prefix> PRIMITIVE PROFILE CAVITY) and adds the column cavity depth (German Minicaphoehe) to Table 6: distance along the bottom wire's normal from the top of the ski to this profile, absolute value, blank where it does not reach.
Plot (collapsed)
Plot type, x-rangeSidecut radius (m) (default) or Curvature (1/m); Full ski (default), Running surface, Between widest points, Between inflection points.
Auto scaleOn (default): fixed band heights (radius 150, baseline 60, profile 100, EI 150 mm), scale fitted to the data. Off: manual scales, baseline and profile 1:1.
Max radius, labels, grid, key lines, ticks, gapMax radius 50 m (above it: plot break, empty table cell). Band titles on (text height 20 mm); grid lines off; key lines off; edge junction ticks on; band gap 50 mm; tick half-length 10 mm.
Stiffness, Tooling blocks, Data table, Output (collapsed)
Target EIOptional EI wire (1 mm = 1 N*m^2): adds the EI band, deflection (mm / 30 kg) and stiffness (lb/in); 3-point bending, rollers at FCP and ACP.
Tip / Tail block, Data table rowsTable 5 block names (typed or from a wire; empty = no row). Data rows default 35, FCP to ACP, plus rows at key locations.
Language, query variableEnglish (default) or Deutsch for tables and band titles. Publish as query variable: primitive (apps expect this name).

Outputs

GeometryClosed composite <prefix> PRIMITIVE (excluded from the BOM) with bands EI, BASELINE, PROFILE, FOOTPRINT, RADIUS or CURVATURE; queries baseline, profileBottom, profileTop, profileCavity, footprint, radius / curvature, ei, primitive.
Tables1 Theoretical scale factors, 2 Metadata, 3 Key locations, 4 SW rout, 5 Baseline, 6 RSL data (x, s, y, w, z, thck, cavity depth, baseline, radius ...).
Variablesprimitive (all tables, schema primitive/1), rsl, averageRadius, natural radii, taper angles, deflection, stiffness, swRout* (read with Extract variables).

Limits and not verified

• Assumed definition: cavity depth = distance along the bottom normal (a vertical distance would be a one-line change). Camber stays small in the scaled band (the range includes tip and tail rise).
• Tested on the “Primitive tests” studio (P20 cavity, P21 off-plane wire: 17 of 17 checks). The older full check script (1:1 bands) was not rerun. Needs a document version first. More: publish_tools/README.md.
