Join profile surfaces

Onshape document Reference_Side_Features  |  Feature sheet, draft 2026-11-06 (FeatureScript 3083)

Join an inside profile surface to outside profile surface(s) across a start and an end split, with a lofted strip at each split and optional fillets, in one feature and one merged surface.

Schematic side view. The inside profile is kept between the splits, the outside profile beyond them; a loft closes each step.

Use it when / not when

Use it when
• a layer steps from one profile surface to another at a split (a ramp, a bump, an end transition)
• every profile can be offset toward one point first
• you want one watertight surface out, with named joint edges to fillet		 Use something else when
• you only need to cut or offset: Split+ or Offset+ alone
• the pieces should stay separate bodies: the merge here is always on

How it works

It replaces the hand steps Offset+ x N, Split+ x N, two lofts and fillets. One inside point drives every side decision.

StepWhat happens
1 OffsetEvery profile is offset with Offset+ toward the inside point (positive toward it, negative away, 0 a copy).
2 SplitSplit+ cuts the inside offset at the splits and keeps the inside (between); the outside offset(s) keep the outside (beyond).
3 LoftEach pair of cut edges (inside cut to outside cut) is lofted into a strip.
4 Merge, filletEverything is united into one surface; fillets go on the merged joint edges.

Quick start

  1. Pick the Start split, the End split, or both (a plane, mate connector, face or sheet).
  2. Pick the Inside point: inside every profile, between the two splits (with one split: on the side the inside profile keeps).
  3. Pick the Inside profile (a sheet body) and its offset.
  4. Choose Outside profiles: one surface for both ends, or different start and end surfaces; pick them and their offsets.
  5. Optional: switch on Start fillet / End fillet and set radius and edge.

The one rule: profiles must reach the splits

Every profile must be actually cut by its split, on the side the inside point implies. A split lying within 0.05 mm of an existing profile edge counts as on it; a cut closer than the 0.01 mm modelling tolerance can leave slivers.

Dialog parameters, outputs, limits

Dialog, in order

End split		One pick each: sheet body, face or mate connector. At least one is required; with one there is a single transition.

Start filletDefault off. Radius (default 5 mm); Start fillet edge Inside (default) or Outside = which joint edge of the loft; Keep opposite start edge (default off) protects the loft's other joint edge (edge overflow on, that edge kept).
End filletSame three controls for the end loft.

Examples

Project test notes (not re-run for this sheet): a stepped join gives 5 faces; an inside offset of 5 and different start / end outside profiles both work; a start fillet on the inside joint works. With only one split, one loft joins the two profiles.

Limits

• The merge is always on; if it fails the feature errors rather than leaving pieces.
• Cut edges shorter than 0.1 mm are dropped before lofting, so a micro edge cannot create extra loft faces. This fix is in the workspace library; a document using an older pinned version does not have it. It was not proven on the user's own geometry (project note).
• Importing documents pin Offset+ and Split+ by microversion: re-pin when they change.
• Fillets need the matching split; “Different” outside profiles are needed only for the splits given.
