Referenced part

Onshape document Reference_Side_Features  |  Feature sheet, draft 2026-11-06 (FeatureScript 3083)

Build a part from reference surfaces with every offset and side read from one reference point. One feature replaces Offset+ x N, Mutual Trim+, Enclose+ / Thicken+, Split+ and a mirror.

Thickened

Constrained

Schematic cross-sections of the two part types. The orange point sets every direction.

Use it when / not when

Use it when
• layers or cores defined by surfaces with offsets (base, mats, glass, top sheet, cores)
• one point (e.g. a mate connector on the centreline) can serve every layer
• the feature goes inside a Case pattern body: one feature, one local name		 Use something else when
• a single step (just offset, thicken, or enclose): Offset+, Thicken+, Enclose+
• a band outside a core (sidewall): make the outline part and the core, then subtract

How it works

Part typeStepsReference point goes
Thickenedoffset the Profile, thicken it (Thicken+), cut by the offset Periphery, cut by the Capsinside the periphery, on the side to thicken
Constrainedoffset Top, Bottom, Periphery; enclose them with the caps (and mirror plane); keep the solid holding the point; cut by the capsinside the part

Thickened thickens before the periphery cut so side walls sit on the periphery instead of tilting with the profile normals. The inputs are never changed: every offset is a new surface, deleted at the end.

Quick start

  1. Pick the Part type, then the Reference point (vertex or mate connector).
  2. Thickened: pick the Profile, set Profile offset and Thickness. Constrained: pick Top and Bottom with their offsets.
  3. Pick the Periphery (required for Constrained) and its offset.
  4. Optional: Cap 1 / Cap 2 with offsets; Mirror plane if the surfaces are one half.
  5. Check the part; negate an offset to move away from the point.

The one rule: positive means toward the point

Each offset and the thickness are signed: positive toward the reference point, negative away, 0 the surface as it is. The point must not lie on a surface it measures.

Examples

Project test notes (not re-run for this sheet): thickened 5 mm; profile offset 2 with thickness -3; periphery cut (4 side faces); a half with a plane cap offset 5, a mirror plane and the point on the plane; constrained with three offsets; caps that divide a closed volume cut it; a point outside the periphery errors.

Limits

• One reference point for all layers; a point that is outside the periphery (Thickened) or the part (Constrained) errors.
• With a mirror plane and a profile offset, the thickened layer is built from the unoffset profile (an offset copy's edges stop short of the plane, which breaks the union).
• Constrained is sensitive to the order its boundary bodies are created in; the feature creates top and bottom offsets first on purpose.
• Not covered: a sidewall band outside a core.
• Importers pin Offset+, Split+ and Thicken+ by microversion: re-pin when they change.
